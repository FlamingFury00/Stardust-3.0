# RLBC 2026 handoff

Rules checked against the [organizer's information document](https://docs.google.com/document/d/1DN0diiGLB6__HzgD42gC3dR-McAl-0fOIkSWqnzB2rs/edit).
The submission deadline is **October 1 AoE**, equivalent to before **October 2, 14:00 Europe/Rome**.
The hardcoded bracket uses RLBot v5; series alternate 3v3, 1v1 and 2v2, with a seven-goal mercy rule.

## Package

Submit the **source ZIP**, which includes the source, `bot.toml` alias, `Stardust.bot.toml`,
`bob.toml`, Linux-container `dockerfile`, loadout, logo, license and a pinned source commit.
Both config names identify the same bot; import only one. Bob uses `Stardust.bot.toml`.
The separate runtime ZIP is for local play/testing and is not a substitute for the source submission.

The Linux Bob build and native package smoke test pass CI. Windows/Ubuntu regressions and native
physics checks also pass. Simulated matches exercise both teams and all three required team sizes.
The loadout uses the default engine audio ID (`0`); the bot has no custom audio playback.
The existing 2048×2048 logo is retained at the owner's request; it is explicitly declared in the config.

Create a source archive from a committed revision:

```powershell
python tools/package_submission.py --output artifacts/releases/Stardust-3.0-RLBC2026-source.zip
```

The archive excludes untracked/ignored files, telemetry and local build output. A checksum sidecar
and `BUILD_INFO.json` identify the exact contents/revision. CI also exports source and runtime archives.

## Required qualification still to record

The rules require a **10-minute 2v2 win against Psyonix Rookie** for hardcoded entrants. This live
qualification has not been run or claimed. RocketSim opponents cannot substitute for Psyonix Rookie.

1. Open Rocket League through the RLBot v5 GUI.
2. Load `rlbc2026/rookie-proof.match.toml`. Its `NoLaunch` setting uses the already-open game.
3. Play the full standard-speed match and retain the automatically saved replay and final score.

The preset uses two Stardust cars, two Rookie cars, normal boost, no state setting, and replay saving.
It intentionally does not apply the tournament's mercy cutoff to this ten-minute qualification.
